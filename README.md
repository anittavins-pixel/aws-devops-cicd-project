# aws-devops-cicd-project
AWS DevOps CI/CD Project | Personal Portfolio Project
Designed and implemented an end-to-end DevOps CI/CD pipeline using Git, GitHub, GitHub Actions, Docker, Jenkins, Amazon EC2, and Amazon ECR.
Developed and deployed a Python Flask web application and managed source code through Git and GitHub version control workflows.
Configured GitHub Actions to automate Continuous Integration (CI) processes, including source code validation and build verification on every code commit.
Built and containerized the application using Docker, creating reusable and portable deployment artifacts through Dockerfiles and container-based workflows.
Provisioned and managed AWS infrastructure components including EC2, VPC, Subnets, Route Tables, Internet Gateway, Security Groups, and IAM.
Installed and administered Jenkins on an AWS EC2 instance using Docker and implemented Pipeline-as-Code using Jenkinsfiles.
Integrated Jenkins with GitHub repositories to automate source code retrieval, validation, and pipeline execution.
Built, tagged, and managed Docker images and prepared deployment-ready artifacts for storage in Amazon Elastic Container Registry (ECR).
Performed Linux system administration tasks including SSH access management, package installation, service monitoring, log analysis, and troubleshooting.
Investigated and resolved issues related to Git workflows, Jenkins pipeline execution, Docker containers, AWS networking, and cloud infrastructure connectivity.
Applied DevOps best practices including automation, Infrastructure as Code concepts, CI/CD, containerization, monitoring, security, and operational documentation.
Gained hands-on experience in cloud networking concepts including TCP/IP, CIDR, VPC design, subnets, routing, firewall rules, and security controls.
Established a scalable foundation for future enhancements involving Terraform, Kubernetes (Amazon EKS), monitoring solutions, and automated deployments.
